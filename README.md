# Spring Boot CRUD Application

A CRUD (Create, Read, Update, Delete) web application developed using Java, Spring Boot, Spring Data JPA, and MySQL.

## Features

- Create user
- Retrieve user details
- Update user details
- Delete user
- Search user by email
- MySQL database integration
- Spring Data JPA and Hibernate

## Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- Spring Tool Suite (STS)
